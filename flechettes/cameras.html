Mode d'emploi

  1. Sur l'iPad : Réglages → Caméras, activez et notez le code. Tapez le même code ici.
  2. Démarrer les caméras, puis choisissez une webcam par cadre.
  3. Pour chaque caméra : Calibrer et cliquez les 4 repères dans l'ordre (bord extérieur du double, sur les fils indiqués). Déplacez-les à la souris jusqu'à ce que le dessin colle à la cible.
  4. Vérifiez : un clic sur l'image affiche la case visée.
  5. Retirez toutes les fléchettes et lancez la Détection.
